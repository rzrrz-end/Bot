# Бот для обратной связи с загрузкой файлов

Telegram-бот, который принимает текстовые сообщения и файлы (фото, документы) от пользователей и пересылает их администратору. Подходит для техподдержки, сбора заявок, жалоб и предложений.

## Функции

- Принимает текст, фото, документы (любые файлы)
- Сохраняет обращения в локальную SQLite базу
- Пересылает сообщение администратору в личный чат или канал
- Автоматически отвечает пользователю об успешном получении

## Как запустить

1. **Клонируй**
   git clone https://github.com/твой-логин/feedback-bot.git
   cd feedback-bot
2. **Установи библиотеки**
     pip install aiogram aiohttp
3. **Получи токен бота у @BotFather** 

4. **Узнай свой ADMIN_CHAT_ID**
Напиши боту любое сообщение в Telegram, перейди по ссылке:
https://api.telegram.org/bot<ТВОЙ_ТОКЕН>/getUpdates
Найди поле chat -> id. Это и есть ID чата. Для канала — обычно отрицательное.

5. **Вставь значения в bot.py:**
  BOT_TOKEN = "твой_токен"
  ADMIN_CHAT_ID = 123456789  # твой ID (без кавычек, число)

6. **Запусти**
  python bot.py


## Команды

    /start — приветствие и инструкция

## База данных

Таблица feedback:

    id — автоинкремент

    user_id — Telegram ID отправителя

    username — юзернейм

    message — текст обращения

    file_id — идентификатор файла в Telegram (если есть)

    created_at — дата и время

## Важно

    Бот должен быть добавлен в канал, если вы используете канал для получения обращений.

    Файлы хранятся на серверах Telegram, их можно скачать по file_id через bot.get_file().

    Бот работает в режиме polling (простой опрос), но для production можно переделать на webhook.
